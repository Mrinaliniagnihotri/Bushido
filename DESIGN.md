## Brand & Style

The design system projects unyielding authority, defensive precision, and refined technological sophistication. Engineered specifically for modern enterprise IT infrastructure and cybersecurity operations across East Africa and global digital markets, the visual posture pairs disciplined restraint with high-performance clarity.

The visual style blends **Apple-inspired light minimalism** with **subtle frosted glassmorphism** and razor-sharp architectural micro-borders:
- **Obsidian Discipline:** Clean, bright canvases layered with precise tonal surfaces provide an immersive, distraction-free environment reminiscent of secure mission-control systems and macOS native pro utilities.
- **Electric Warm Amber Accent:** A high-visibility warm amber provides a singular dynamic focal point, reserved for vital interactions, security states, active indicators, and high-priority metrics.
- **Precision Engineered Feel:** Micro-borders (1px at 8–15% opacity), subtle linear surface gradients, and deliberate optical spacing deliver a tactile, elite enterprise presence.

## Colors

The palette is tuned exclusively for high-light clarity and visual hierarchy, anchoring on clean minimalist canvases, structured slate neutrals, and high-impact functional amber.

### Palette Roles
- **Primary (`#FEC300` / Amber Bright):** Used deliberately for key call-to-actions, focused outlines, critical status badges, and active navigation nodes.
- **Secondary (`#CAAC05` / Slate Metallic):** Supporting metadata, passive icons, secondary labels, and structural dividers.
- **Tertiary (`#9D9E05` / Amber Burnished):** Used for hover accents, warning/alert status layers, and complementary metric graphs.
- **Neutral Canvas (`#F9F9FB`):** Base canvas background, providing crisp bright depth.
- **Surface Elevation Levels:**
  - `surface-base`: `#F9F9FB` (Underlying screen background)
  - `surface-elevated`: `#FFFFFF` (Cards, panels, list containers)
  - `surface-overlay`: `rgba(255, 255, 255, 0.72)` (Frosted glass floating overlays, modals, headers)
  - `surface-interactive`: `#F1F1F4` (Inputs, hovering list tiles, pill backgrounds)
- **Borders & Separators:**
  - `border-subtle`: `rgba(0, 0, 0, 0.08)`
  - `border-strong`: `rgba(0, 0, 0, 0.16)`
  - `border-accent`: `rgba(254, 195, 0, 0.45)`
- **Typography Tones:**
  - `text-primary`: `#111115` (Headings, primary figures, dominant content)
  - `text-secondary`: `#5E5E66` (Body, field inputs, standard navigation)
  - `text-tertiary`: `#8E8E93` (Captions, timestamps, disabled indicators)
  - `text-accent`: `#CAAC05` (Interactive links, active tags)

## Typography

The typographic hierarchy emphasizes optical cleanliness, legibility, and technical authority, leveraging tight letter-spacing for large display text and open tracking for micro metadata.

- **Scale & Contrast:** High contrast between dark headlines (`#111115`) and slate body text (`#5E5E66`) maintains clear visual hierarchy without causing eye fatigue on light backdrops.
- **Monospace Pairing:** A dedicated `code-sm` token using **JetBrains Mono** handles cybersecurity indicators, IP ranges, SHA hashes, timestamp logs, and telemetry values.
- **Uppercase Labels:** The `label-sm` role utilizes uppercase rendering with `0.06em` letter spacing for category tags, threat levels, and section super-headers.

## Layout & Spacing

The layout is built on a responsive 12-column grid system bounded by maximum widths of `1280px` for standard views and `1440px` for data-heavy security consoles.

### Breakpoints & Adaptive Rhythm
- **Desktop (1024px+):** 12 columns with `1.5rem` (`24px`) gutters and `3rem` (`48px`) outer canvas margins. Full multi-column dashboard card layouts and navigation docks.
- **Tablet (768px – 1023px):** 8 columns with `1.25rem` (`20px`) gutters and `2rem` (`32px`) margins. Sidebars collapse into glass slide-out sheets.
- **Mobile (Up to 767px):** 4 columns with `1rem` (`16px`) gutters and `1.25rem` (`20px`) outer margins. Content reflows vertically into structured stacked cards.

Vertical page flow uses rhythmic units: `space-xl` for section separation, `space-lg` for card internal padding, and `space-xs`/`space-sm` for inline metadata locks.

## Elevation & Depth

Visual depth is achieved through layered tonal surfaces, Apple-grade frosted glass, and precise micro-borders rather than heavy dropshadows.

### Structural Depth Tiers
1. **Canvas Level (Ground):** Solid `#F9F9FB`. Non-interactive backdrop.
2. **Card & Panel Layer:** `#FFFFFF` with a top-to-bottom subtle gradient (`rgba(0,0,0,0.01)` to `rgba(0,0,0,0)`), framed with a hairline micro-border: `1px solid rgba(0, 0, 0, 0.07)`.
3. **Glassmorphism Floating Elements (Headers, Dock, Flyouts):**
   - Background: `rgba(255, 255, 255, 0.75)`
   - Backdrop Filter: `blur(20px) saturate(180%)`
   - Border: `1px solid rgba(0, 0, 0, 0.1)`
   - Shadow: `0 8px 32px rgba(0, 0, 0, 0.08)`
4. **Interactive Focus & Hover States:**
   - Elements elevate by gaining an amber glow halo: `0 0 0 1px rgba(254, 195, 0, 0.4), 0 4px 20px rgba(254, 195, 0, 0.12)`.

## Shapes

The shape grammar adheres to modern precision hardware standards—refined smooth curves that soften light surfaces without appearing overly playful.

- **Base Radius (`0.5rem` / 8px):** Applied to form fields, badge tags, list items, and standard action buttons.
- **Large Radius (`1rem` / 16px):** Applied to content cards, dashboard diagnostic panels, and dropdown containers.
- **Extra-Large Radius (`1.5rem` / 24px):** Applied to modal dialogs, security scan detail drawers, and floating bottom navigation capsules.
- **Full Pill (`9999px`):** Exclusively reserved for status chips, live monitoring pills, and minimal secondary icon triggers.

## Components

### Buttons
- **Primary (Accent):** Solid `#FEC300` background, `#111115` bold text, `rounded` (8px). On hover: `#CAAC05` with soft amber glow.
- **Secondary (Light Glass):** Background `rgba(0, 0, 0, 0.03)`, text `#111115`, border `1px solid rgba(0, 0, 0, 0.08)`. On hover: background `rgba(0, 0, 0, 0.06)`, border `rgba(0, 0, 0, 0.15)`.
- **Ghost/Tertiary:** Transparent background, `#5E5E66` text. On hover: `#111115` text with subtle ambient background `rgba(0, 0, 0, 0.04)`.

### Cards & Panels
- Constructed from `#FFFFFF` with `rounded-lg` (16px) curvature and `1.5rem` internal padding.
- Encased with a `1px` subtle border `rgba(0, 0, 0, 0.07)`.
- Interactive cards feature a hover lift with border illumination shifted to `rgba(254, 195, 0, 0.3)`.

### Input Fields
- Background `#F1F1F4`, height `44px`, border `1px solid rgba(0, 0, 0, 0.1)`, text `#111115`, placeholder `#8E8E93`.
- Focus state: border shifts to `#FEC300`, accompanied by an amber hairline box shadow `0 0 0 3px rgba(254, 195, 0, 0.15)`.

### Badges & Chips
- Status indicators styled with pill-shaped geometry (`rounded-full`), `11px` uppercase typography, and `space-xs` vertical by `space-sm` horizontal padding.
- Active/Operational: Background `rgba(254, 195, 0, 0.12)`, text `#9D9E05`, border `1px solid rgba(254, 195, 0, 0.25)`.
- Neutral/Standby: Background `rgba(0, 0, 0, 0.05)`, text `#5E5E66`, border `1px solid rgba(0, 0, 0, 0.08)`.

### Checkboxes & Switches
- **Checkboxes:** 18px box, `4px` corner radius, `1px solid rgba(0, 0, 0, 0.2)`. Checked state fills with `#FEC300` and a dark `#111115` check icon.
- **Switches:** Apple-style smooth capsule track (`#E5E5EA`), thumb `#FFFFFF`. When active: track transitions to `#FEC300` and thumb shifts to `#111115`.

### Security Status Metric Tiles
- Dedicated telemetry component: clean glass base, large monospace metric display, trend indicators with directional micro-arrows, and top-right status dot glowing in amber.
